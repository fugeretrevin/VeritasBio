Limitations
------------------------------------------------------------------------------
  - Library 'eqfp611_red' declares 0 imputed records, but that is THIS repository's declaration and not an upstream per-record flag, so the labels remain HISTORICAL_UNKNOWN_PROVENANCE. Verify against the source publication before describing them as measured. Same library and same source table as eqfp611_blue, different endpoint column. NOT an independent landscape from eqfp611_blue. Same 3M24 caveat at positions 63, 174 and 231. Best observed variant in the prepared table: D20N:L63M:T127P:F143S:A172C:Y197R:N206D. Imputation status for this table has not been established; the zero imputed count is an absence of evidence, not evidence of absence.
  - Do NOT assume that because every method searches the same contaminated universe the comparison between methods is unbiased. The contamination is not independent of the methods: the published KNN-imputed values sit wherever sequencing coverage was poorest, which is not uniform over the landscape. If imputed records cluster in the region one method prefers to explore, that method is scored against model output while another is scored against measurements, and the bias is DIFFERENTIAL, not common-mode. Nothing in this run bounds that effect, and no shared-universe argument removes it.
  - Methods diverge after the shared starting sample, so per-round comparisons are paired only at round 0.
  - panoptes_default / panoptes_muse exercise production planning, selection and (live only) reflection. Gatekeeper authorisation and Modal ESM-2 execution are not exercised, because Orchestrator.run_stream() has no interface for substituting an experimental assay for ESM scoring in step 5.
  - panoptes_default plans from the target's annotated active sites (metadata.binding_positions), not from a per-target script. It deliberately does NOT use workers.mock_workers.MockLLMWorker, whose TrpB branch hardcodes positions 183/184/227/228 and suggests three of the four global-optimum residues - that would encode the answer this benchmark measures the discovery of.
  - panoptes_muse is given this library's saturated positions as its assayable scope, which is enforced deterministically on the planner's output. Without it the planner proposed distal allosteric residues the four-site library cannot measure and whole rounds were discarded as not_in_eligible_universe. Check the accepted/requested columns in round_metrics.csv: a short batch still means proposals were rejected.
  - Token usage is unknown: controller/orchestrator.py discards the provider's usage block.
  - Top-1% membership is defined over the eligible set in this run; a different eligibility filter changes the threshold.
